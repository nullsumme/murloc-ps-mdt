# UnitFlags3

 

Returns the ` flags3 ` of a Unit.

 

```lua
flags3 = UnitFlags3(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **flags3**
  
  - ` number ` : flags3

 



 

## Details

 

Contains valuable information on the Unit.
