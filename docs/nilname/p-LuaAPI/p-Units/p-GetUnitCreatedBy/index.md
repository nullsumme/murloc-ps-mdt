# GetUnitCreatedBy

 

Returns the creator of a Unit.

 

```lua
creator = GetUnitCreatedBy(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **creator**
  
  - ` number|nil ` : Nn Object that represents the creator, if any
