# GetUnitLootable

 

Returns if a Unit is lootable.

 

```lua
isLootable = GetUnitLootable(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **isLootable**
  
  - ` boolean ` : is lootable
