# DynamicFlags

 

Return the dynamic flags for the given Unit.

 

```lua
dynamicFlags = DynamicFlags(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **dynamicFlags**
  
  - ` number ` : dynamic flags

 



 

## Details

 

Dynamic flags holds interesting information about the Unit (NPC/Player)
