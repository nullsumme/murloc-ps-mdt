# CombatReach

 

Return the combat range of the Unit.

 

```lua
range = CombatReach(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **range**
  
  - ` number ` : The combat range
