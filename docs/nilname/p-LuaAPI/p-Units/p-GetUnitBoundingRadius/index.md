# GetUnitBoundingRadius

 

Return the bounding radius of a Unit.

 

```lua
radius = GetUnitBoundingRadius(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **radius**
  
  - ` number ` : bounding radius
