# ObjectBoundingRadius

 

Returns the bounding radius of a Nn Object.

 

```lua
radius = ObjectBoundingRadius(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **radius**
  
  - ` number ` : Radius in yards
