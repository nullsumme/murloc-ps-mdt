# ObjectFlags

 

Returns the "flags" from a given Nn Object.

 

```lua
flags = ObjectFlags(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **flags**
  
  - ` number ` : Flags
