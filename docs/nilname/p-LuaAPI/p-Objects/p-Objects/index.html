Objects

Aliases: GetObjects, Objects

Returns a set of numbers that represent Nn objects.

objects = Objects()

Returns

  • objects
    • table : List of numbers that each reference a unique objects

Details

Objects maybe be use by pretty much any other Nn Object API to interact with

The range of the Object Manager is often limited to 100y radius in open world, but may be extended in smaller intances like dungeons or battlegrounds where the whole instance may be covered regardless of the 100y range rule.
