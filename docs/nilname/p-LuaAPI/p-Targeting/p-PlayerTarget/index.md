# PlayerTarget

 

Returns the target of the current local player (you).

 

```lua
target = PlayerTarget()
```

 



 

## Returns

 

- **target**
  
  - ` number ` : The Object being targeted by you, the local player

 



 

## Details

 

This is just a fancy way of obtaining the ` "target" ` as a Nn Object.
