GetCorpsePosition

Returns the world coords of the current active Camera.

x, y, z = GetCorpsePosition()

Returns

  • x
    • number : The X-axis world coord
  • y
    • number : The Y-axis world coord
  • z
    • number : The Z-axis world coord

Details

Please note that, in some rare cases, the XYZ position may be in another world/map/instance.
