# ClickToMove

 

Makes your player move, in a direct line, to a specified XYZ world location.

 

```lua
ClickToMove(x, y, z)
```

 



 

## Arguments

 

- **x**
  
  - ` number ` : The X-axis world coord 
- **y**
  
  - ` number ` : The Y-axis world coord 
- **z**
  
  - ` number ` : The Z-axis world coord
