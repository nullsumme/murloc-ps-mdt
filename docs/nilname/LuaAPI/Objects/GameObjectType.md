# GameObjectType

 

Returns the GameObjectType of a Nn Object.

 

```lua
type = GameObjectType(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **type**
  
  - ` number ` : Represents the Object Type of the give ` object `

 



 

## Details

 

This is unique to the GameObject objects and differs from [` ObjectType `](https://docs.nilname.com/LuaAPI/Objects/ObjectType/)
