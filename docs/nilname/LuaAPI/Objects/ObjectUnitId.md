# ObjetUnitId

 

Returns the id of a NPC

 

```lua
id = ObjetUnitId(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **id**
  
  - ` number ` : The identifier (id) for the given NPC

 



 

## Details

 

To get the id of a GameObject, see [ObjectId](https://docs.nilname.com/LuaAPI/Objects/ObjectId/)
