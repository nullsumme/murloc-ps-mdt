# ObjectHeight

 

Returns the height of a NPC.

 

```lua
height = ObjectHeight(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **height**
  
  - ` number ` : Height of the object
