# ObjectSkinnable

 

Returns True if the NPC is skinnable

 

```lua
isSkinnable = ObjectSkinnable(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **isSkinnable**
  
  - ` boolean ` : True if NPC is skinnable

 



 

## Details

 

This will only work on NPCs
