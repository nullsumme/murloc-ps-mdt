# ObjectLootable

 

Returns true if a given NPC is lootable.

 

```lua
lootable = ObjectLootable(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **lootable**
  
  - ` boolean ` : Returns True if the object (NPC) is lootable

 



 

## Details

 

You may want to use [ObjectInteract](https://docs.nilname.com/LuaAPI/Objects/ObjectInteract/) to start looting the NPC
