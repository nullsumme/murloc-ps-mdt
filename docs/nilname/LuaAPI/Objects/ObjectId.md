# ObjectId

 

Returns the id of a GameObject

 

```lua
id = ObjectId(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **id**
  
  - ` number ` : The identifier (id) for the given GameObject

 



 

## Details

 

To get the id of a NPC, see [ObjectUnitId](https://docs.nilname.com/LuaAPI/Objects/ObjectUnitId/)
