# ObjectFacing

 

Returns the facing of a Nn Object.

 

```lua
facing = ObjectFacing(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **facing**
  
  - ` number ` : Return a number between ` 0 ` and ` pi*2 `
