# GetObjectType

 

Returns the Type of a Nn Object.

 

```lua
type = GetObjectType(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **type**
  
  - ` number ` : Represents the Object Type of the give ` object `

 



 

## Details

 

The follow objects types exist:

 

```c
5 - NPC
6 - Player
7 - LocalPlayer
8 - GameObject
```
