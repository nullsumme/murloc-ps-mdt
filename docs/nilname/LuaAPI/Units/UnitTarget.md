# UnitTarget

 

Returns the target of a Unit.

 

```lua
target = UnitTarget(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **target**
  
  - ` number|nil ` : Nn Object that represents the target, if any
