# UnitFlags

 

Returns the ` flags ` of a Unit.

 

```lua
flags = UnitFlags(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **flags**
  
  - ` number ` : flags

 



 

## Details

 

Contains valuable information on the Unit.
