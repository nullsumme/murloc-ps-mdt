# UnitFlags2

 

Returns the ` flags2 ` of a Unit.

 

```lua
flags2 = UnitFlags2(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **flags2**
  
  - ` number ` : flags2

 



 

## Details

 

Contains valuable information on the Unit.
