# UnitFacing

 

Returns the facing of a Unit.

 

```lua
facing = UnitFacing(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **facing**
  
  - ` number ` : Return a number between ` 0 ` and ` pi*2 `
