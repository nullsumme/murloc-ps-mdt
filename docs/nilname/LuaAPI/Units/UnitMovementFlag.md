# UnitMovementFlag

 

Returns the Movement Flags of a Unit.

 

```lua
movFlags = UnitMovementFlag(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **movFlags**
  
  - ` number ` : Movement flags

 



 

## Details

 

These flags indicate the movement of an object, if its moving at all, and the direction of the movement *(forward/backward/jump/fall/fly/...)*
