# GetUnitSummonedBy

 

Returns the summoner of a Unit.

 

```lua
summoner = GetUnitSummonedBy(object)
```

 



 

## Arguments

 

- **object**
  
  - ` number ` : Nn Object identifier

 



 

## Returns

 

- **summoner**
  
  - ` number|nil ` : Nn Object that represents the summoner, if any
