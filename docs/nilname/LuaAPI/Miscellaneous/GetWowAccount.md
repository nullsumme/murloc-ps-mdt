# GetWowAccount

 

Returns the wow account *(unique to Wow1, Wow2, ...)*

 

```lua
accountname = GetWowAccount()
```

 



 

## Returns

 

- **accountname**
  
  - ` string ` : The Wow account name

 



 

## Details

 

The account name is unique to a pair of bnet + game account. The game account index is often showen at the end as e.g. ` #1 ` or ` #3 `.
