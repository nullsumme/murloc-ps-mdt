# ClickPosition

 

Performs a left-click in the 3D world space.

 

```lua
ClickPosition(x, y, z)
```

 



 

## Arguments

 

- **x**
  
  - ` number ` : The X-axis world coord 
- **y**
  
  - ` number ` : The Y-axis world coord 
- **z**
  
  - ` number ` : The Z-axis world coord

 



 

## Details

 

This is often used for AoE spellcasting, not for movement. If you are looking for click-to-move thing, check out [` ClickToMove `](https://docs.nilname.com/LuaAPI/Movement/ClickToMove/) instead.
