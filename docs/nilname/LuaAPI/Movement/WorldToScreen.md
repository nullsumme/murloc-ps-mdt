# WorldToScreen

 

Convertes a 3D World XYZ into a 2D screen/pixel coord.

 

```lua
x, y = WorldToScreen(x, y, z)
```

 



 

## Arguments

 

- **x**
  
  - ` number ` : World X-Axis 
- **y**
  
  - ` number ` : World Y-Axis 
- **z**
  
  - ` number ` : World Z-Axis

 



 

## Returns

 

- **x**
  
  - ` number ` : X-Axis screen coord *(in pixels)* 
- **y**
  
  - ` number ` : Y-Axis screen coord *(in pixels)*
